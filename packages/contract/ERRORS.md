# エラーコードと画面文言（K-05）

この表は[src/errors.ts](src/errors.ts)から生成します。直接編集せず、`npm run contract:generate`を実行してください。

APIはcodeとrequest_idを返し、FEはこの文言を表示します。再試行可能でも投稿キューは最大3回、AI処理は最大2回で停止します。PROCESSING_HELDは再投稿を促さず状態確認・運営対応へ案内します。

| コード                    | HTTP       | 画面表示                                                                             | 再試行                   |
| ------------------------- | ---------- | ------------------------------------------------------------------------------------ | ------------------------ |
| AUTH_REQUIRED             | 401        | Googleアカウントでログインしてください。                                             | 自動再送しない           |
| FORBIDDEN                 | 403        | この操作を行う権限がありません。                                                     | 自動再送しない           |
| CONSENT_REQUIRED          | 403        | 最新の利用規約を確認し、同意してください。                                           | 自動再送しない           |
| ACCOUNT_BANNED            | 403        | 投稿が制限されています。異議申立てをご利用ください。                                 | 自動再送しない           |
| NOT_FOUND                 | 404        | 投稿が見つからないか、公開されていません。                                           | 自動再送しない           |
| INVALID_INPUT             | 400        | 入力内容を確認してください。                                                         | 自動再送しない           |
| INVALID_CURSOR            | 400        | 一覧を更新して、もう一度お試しください。                                             | 自動再送しない           |
| EVENT_CLOSED              | 409        | 現在、このイベントへの投稿は受け付けていません。                                     | 自動再送しない           |
| PUBLICATION_STOPPED       | 503        | 運営による確認のため、公開と投稿を一時停止しています。                               | 自動再送しない           |
| THEME_UNAVAILABLE         | 409        | このお題は受付を終了しました。お題を選び直してください。                             | 自動再送しない           |
| STATE_CONFLICT            | 409        | 投稿の状態が変わりました。最新の状態を確認してください。                             | 自動再送しない           |
| IDEMPOTENCY_CONFLICT      | 409        | 送信内容が変わっています。投稿状態を確認してください。                               | 自動再送しない           |
| RATE_LIMITED              | 429        | 投稿が集中しています。少し待ってからお試しください。                                 | 可（待機と回数上限あり） |
| UPLOAD_EXPIRED            | 410        | アップロードの有効期限が切れました。再送信してください。                             | 可（待機と回数上限あり） |
| UPLOAD_INCOMPLETE         | 409        | アップロードがまだ完了していません。送信を続けてください。                           | 可（待機と回数上限あり） |
| PROVIDER_LIMIT            | 413        | 保存サービスの制約により送信できません。運営へお問い合わせください。                 | 自動再送しない           |
| UNSUPPORTED_MEDIA         | 422        | この形式の変換に失敗しました。原本の保存状況を確認しています。                       | 自動再送しない           |
| VIDEO_TOO_LONG            | 422        | 動画を4秒以内に処理できませんでした。再処理をお待ちください。                        | 自動再送しない           |
| PROCESSING_HELD           | 503        | 処理の確認中です。公開せず保留しています。                                           | 自動再送しない           |
| CONTENT_BLOCKED           | 422        | 公開基準により投稿できませんでした。異議申立てをご利用ください。                     | 自動再送しない           |
| LOCAL_STORAGE_UNAVAILABLE | 端末内のみ | この端末に送信待ちデータを保存できません。空き容量やブラウザ設定を確認してください。 | 自動再送しない           |
| NETWORK_UNAVAILABLE       | 端末内のみ | 接続を確認して、この画面を開いたままお待ちください。                                 | 可（待機と回数上限あり） |
| INTERNAL_ERROR            | 500        | 処理に失敗しました。時間をおいてお試しください。                                     | 可（待機と回数上限あり） |
