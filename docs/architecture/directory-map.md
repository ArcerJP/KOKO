## 登録表の保守

永続パスを追加、削除、または実質的に用途変更する場合は、extension-policy.mdに従った後でこの登録表を更新します。各パスには、明確な責務、正本性、読込時点、書込ポリシー、Gitポリシー、ライフサイクルを1つずつ定義しなければなりません。
